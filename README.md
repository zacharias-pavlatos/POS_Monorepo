
### Stack overview

Below is an overview of all the components in the stack:

```
apps
  ├─ web
  |   ├─ nextjs
  |   ├─ tanstack query
  |   ├─ react hook form
  |   └─ tailwindcss
  ├─ server
  |   └─ hono (wrapper for api & auth)
packages
  ├─ api
  |   └─ orpc with zod
  ├─ auth
  |   └─ better-auth
  ├─ db
  |   └─ drizzle-orm (postgres database)
  ├─ ui
  |   ├─ tailwindcss
  |   └─ shadcn & radix ui
tools
  ├─ eslint
  ├─ prettier
  ├─ tailwind
  └─ typescript
```
